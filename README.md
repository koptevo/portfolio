# Мастерская сайтов

Портфолио-визитка без имени и фамилии: показывает клиенту, что делается и сколько это стоит.

**Живой адрес:** https://koptevo.github.io/portfolio/
**Демо барбершопа:** https://koptevo.github.io/portfolio/works/barbershop/

## Как обновить сайт

После правок в папке `portfolio`:

```
git add -A
git commit -m "что изменил"
git push
```

GitHub Pages пересоберёт сайт за минуту — обнови страницу с `Ctrl+F5`.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | текст и структура страницы |
| `styles.css` | внешний вид (цвета — в блоке `:root` сверху) |
| `script.js` | меню на телефоне, анимация появления, год в подвале |

## Как посмотреть

Открой в браузере: **http://127.0.0.1:5500/**

(Это локальный сервер. Если он остановился — в папке проекта можно дважды кликнуть `index.html`, но тогда часть эффектов может не работать.)

## Как открыть в VS Code

1. Пуск → набери `Visual Studio Code` → Enter.
2. `Файл` → `Открыть папку…` → выбери `portfolio`.
3. Слева будут три файла. Правь текст в `index.html`, сохраняй `Ctrl+S` — обнови вкладку в браузере, увидишь изменения.

## Как выложить в интернет

Два пути. Первый — за две минуты, второй — «по-взрослому», с историей изменений.

### Быстро: Netlify Drop

1. Открой **app.netlify.com/drop**.
2. Перетащи в окно файл `portfolio-site.zip` (он лежит в папке проекта, на уровень выше).
3. Войди через Google или почту — Netlify попросит аккаунт, чтобы сайт не удалился.
4. Получишь адрес вида `https://случайное-имя.netlify.app` — его уже можно отправлять клиентам.
5. Обновить сайт: `Deploys` → перетащить новый zip.

### По-взрослому: GitHub Pages

Репозиторий уже создан локально (первый коммит `97a0567`), осталось загрузить.

1. Создай аккаунт на GitHub — **вместе с родителем**: сервис публичный, и по правилам до 18 лет нужно согласие.
2. New repository → имя `portfolio` → **без** README и .gitignore → Create.
3. В терминале VS Code (`Ctrl+`` ` ``) выполни, подставив свой ник:

```
cd portfolio
git remote add origin https://github.com/ТВОЙ_НИК/portfolio.git
git push -u origin main
```

4. На GitHub: Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
5. Через минуту: `https://ТВОЙ_НИК.github.io/portfolio/`

При первом `push` GitHub попросит войти — откроется браузер, это нормально.

### Что важно знать

- `_shots`, `_deploy`, `_backup_v1` — рабочие папки, в архив и репозиторий они не попадают.
- Сайт статический: сервер нужен только для локального просмотра, для хостинга — нет.
- `?static` в адресе отключает анимации — это для скриншотов, посетителям не мешает.
